## 📌 Overview

This project is an **educational research framework** demonstrating:

- Raw socket programming in C  
- Custom ASCII art rendering  
- Terminal animation effects (Matrix rain, neon pulses, loading bars)  
- Packet structure exploration (IP/TCP headers)  
- Banner/visual UI customization for terminal tools  

⚠️ **This project is NOT a DDoS tool, NOT an attack tool, and must NEVER be used on real systems.**  
Its purpose is strictly:

- Learning  
- Practicing C low-level networking  
- Visual terminal animation design  
- Ethical cybersecurity education
